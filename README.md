## About the Project

A **comprehensive Android Jetpack masterclass**, inspired by:  
> _“Android Jetpack Masterclass in Java”_ by **Catalin Stefan**

This is a study project to explore and demonstrate **modern Android development** with **Jetpack**, **Java**, and **MVVM**.

---

## Technologies Covered

| Jetpack Core 📦     | Architecture & UI 🧩   | Additional Libraries ⚙️     |
|---------------------|------------------------|------------------------------|
| Navigation           | ViewModel              | Retrofit                     |
| Room                 | LiveData               | RxJava                       |
| Data Binding         | MVVM Pattern           | Glide                        |
| AndroidX             | Fragments & Layouts    | Multidex                     |
| KTX Extensions       | DataStore / Preferences| Palette                      |
| Lifecycle Mgmt       | Notifications          | Sharing & Permissions        |

---

## Project Goals

- Showcase **Jetpack component** proficiency  
- Implement **clean architecture (MVVM)**  
- Apply **modern best practices**  
- Offer a **real-world Java reference**
